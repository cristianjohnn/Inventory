# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [1.0.0] - 2026-04-06

### Added
- Asset management (CRUD) for 7 categories: Laptop, Monitor, Server, Phone, Printer, Networking, Peripheral
- Depreciation engine with 3 methods: Straight-Line, Double Declining Balance, Units of Production
- Employee assignment with full audit trail
- Dashboard with summary cards, portfolio valuation, charts, and recent activity feed
- Search and filter by name, serial number, employee, status, and category
- CSV export for asset data
- Dark/light mode with system preference detection
- Docker Compose setup for development (PostgreSQL) and production (full stack with Nginx)
- Comprehensive documentation: README, CONTRIBUTING, ARCHITECTURE, BRANCH_STRATEGY, COLLABORATORS
- GitHub collaboration setup: CODEOWNERS, PR template, CI workflow
- Seed data with 7 sample assets
